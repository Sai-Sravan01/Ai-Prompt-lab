These are the Things i learned from my mistakes
We need to follow the R-C-T-O principle because it makes our thoughts more clear so that the ai chatbot give clear answer 
ROLE
CONTEXT
TASK
OUTPUT 

We usually ask our doubts or questions in a ai platform and it gives reply based on our prompt
So i tried some of the prompts 

Prompt-01:
--Teach me python..
Reply: It was so long answer with no clear roadmap and it seems to be like a text book answer

So i used this:
I am a Student.Btech Fresher and i am interested to learn python.Give a clear roadmap under 150 words

Prompt-02:
--Write code for caluclator..
Reply : The code is very complicated and some times it can give the output in different computer language 

So i used this:
I am a Student and i just started learning python so i want to do a mini caluclator project so give the code required to do that under 50 lines

It looks like simple but the difference is very big.I just extended one line and whole output has changed
